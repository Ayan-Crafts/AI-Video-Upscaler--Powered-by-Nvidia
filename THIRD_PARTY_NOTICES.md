# Third-party notices

Potential integrations and redistribution review requirements:

- FFmpeg: LGPL/GPL obligations depend on the exact build and enabled components.
- PySide6/Qt: LGPLv3 or commercial terms; deployment must comply with Qt licensing.
- PyTorch/torchvision: BSD-style project licenses; CUDA components have separate NVIDIA terms.
- RIFE/Practical-RIFE: check exact upstream source and checkpoint terms before redistribution.
- Real-ESRGAN: review source and each model checkpoint separately.
- nvidia-ml-py: NVIDIA Management Library Python bindings; display driver remains externally installed.
- psutil: BSD-3-Clause.

No model weights are bundled in this development baseline. Future model downloads must display the upstream source, license, version and expected SHA-256.
