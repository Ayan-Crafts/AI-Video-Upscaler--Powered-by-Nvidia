Model checkpoints are downloaded from upstream URLs at runtime. They are not included in this source tree. Model source URLs, computed SHA-256 values and file sizes are recorded next to the downloaded files in the user's model cache. Where upstream does not publish a checksum, the computed digest is a record, not an independent authenticity guarantee.
